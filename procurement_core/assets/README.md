# Google sign-in button

`google-signin.png` is Google's unmodified pre-approved Android/Web light,
rectangular button at 2x resolution. It is displayed at 40 CSS pixels tall with
its original aspect ratio. The image contains the official logo and button text;
the page does not substitute a font or redraw the logo.

Source: https://developers.google.com/static/identity/images/signin-assets.zip

Usage guidance: https://developers.google.com/identity/branding-guidelines

Downloaded September 26, 2026 for the hosted sign-in page. Google brand assets
remain subject to Google's brand-usage rules.
