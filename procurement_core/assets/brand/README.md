# Corporate blog typefaces

Fraunces, Inter Tight and JetBrains Mono match the live Warre & Vavasour site.
These Latin variable WOFF2 faces are served locally; reading the blog does not
request a font from a third party. Each family retains its SIL Open Font License
beside the font files.

Sources: [Google Fonts](https://fonts.google.com/), with the family licences in
the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).

The blog palette, wordmark treatment and type choices follow
`warre-vavasour/src/styles.css`. The blue archival sign-in page remains its own
existing product flow.
